# 25-model-switching — Стратегии переключения моделей

Когда и как переключаться между GPT, Grok и Claude в одном проекте.

## Лучшие комбинации:

- **Grok** → быстрый brainstorming + первые черновики
- **Claude** → глубокая проработка, архитектура, анализ
- **GPT** → финализация, голос, интеграции, Canvas
