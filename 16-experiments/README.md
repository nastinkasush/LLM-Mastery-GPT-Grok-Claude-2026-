# 16-experiments — Эксперименты и бенчмарки

Здесь мы тестируем модели в реальных сценариях и фиксируем результаты.

## Проведённые эксперименты

### 1. Coding Battle (май 2026)
- Задача: Создать полноценное веб-приложение (Next.js + Supabase)
- **Победитель**: Claude 3.7 Sonnet (лучшая архитектура и чистота кода)
- **2 место**: GPT-4.5 o3
- **3 место**: Grok 4 (быстрее всех, но больше мелких ошибок)

### 2. Креативный тест — Написание продающего текста
- **Победитель**: Grok 4 (самый живой и убедительный стиль)

### 3. Анализ большого документа (150 страниц)
- **Победитель**: Claude 3.7 (лучше всего держит контекст)

### 4. Скорость ответа
- **Победитель**: Grok 4 (значительно быстрее)
