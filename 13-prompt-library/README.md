# 13-prompt-library — Библиотека промптов

Самая полезная часть репозитория. Здесь собраны проверенные, мощные промпты для GPT, Grok и Claude.

## Структура библиотеки

- [general](./general) — Универсальные промпты
- [coding](./coding) — Программирование
- [creative](./creative) — Креатив и контент
- [analysis](./analysis) — Анализ и исследования
- [business](./business) — Бизнес и продуктивность
- [role-playing](./role-playing) — Ролевые промпты
- [advanced](./advanced) — Продвинутые / агентные промпты

---

### Примеры промптов:

Если не уверен — говори об этом прямо.
