# 30-mistakes-and-anti-patterns — Типичные ошибки и антипаттерны

Самые частые ошибки при работе с LLM и как их избегать.

## ТОП-15 ошибок

1. Слишком размытый промпт
2. Перегруженный одним сообщением контекст
3. Игнорирование сильных и слабых сторон моделей
4. Неиспользование Chain of Thought
5. Доверие модели без проверки (hallucinations)
6. Плохое управление памятью
7. Использование одной модели для всех задач

[how-to-fix.md](./how-to-fix.md) — как исправлять
