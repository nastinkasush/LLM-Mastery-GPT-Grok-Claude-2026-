# 08-context-engineering — Инженерия контекста

Как эффективно работать с большим контекстом (от 32K до 200K+ токенов) в GPT, Grok и Claude.

## Основные принципы

1. **Иерархический контекст** — сначала давай общую картину, потом детали
2. **Релевантность > Объём** — лучше меньше, но важнее
3. **Chunking** — разбиение больших документов
4. **Summarization** — предварительное сжатие информации
5. **Progressive Context** — постепенное добавление информации

## Лучшие практики 2026

### Для Claude (лучше всего держит контекст)
- Используй Projects + большой CLAUDE.md
- Добавляй ключевые факты в начало

### Для Grok
- Используй короткие, чёткие инструкции в начале
- Grok лучше работает с более динамичным контекстом

### Для GPT
- Используй Custom Instructions + Canvas
- Разделяй длинные разговоры на несколько чатов
