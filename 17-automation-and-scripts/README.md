# 17-automation-and-scripts — Автоматизация и скрипты

Как автоматизировать рутинные задачи с помощью GPT, Grok и Claude.

## Что можно автоматизировать

- Автоматическая генерация отчётов
- Парсинг и обработка данных
- Массовое создание контента
- Авто-ответы и обработка почты
- Тестирование промптов (Prompt Testing Framework)

## Полезные инструменты 2026

- n8n + LLM
- Make.com + Claude/Grok
- Python + LangChain/LangGraph
- Custom scripts для Claude Computer Use
